# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

This tool is for **educational simulation only**. It does not process real data or connect to real databases.

However, if you find a vulnerability in the tool itself (e.g., a way to crash the CLI or execute code on the user's machine via the input prompt), please report it.

### Reporting Process

1. Email the issue to suryanshunab@gmail.com.
2. We will respond within 48 hours.
3. Please do not disclose publically until a fix is available.

## Ethical Use

By using this software, you agree to use it only for educational and defensive purposes. The authors assume no liability for misuse of the concepts demonstrated herein.
